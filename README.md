# JS_PE1 – Mi Primer Script Interactivo

## Descripción del proyecto

Este repositorio contiene el desarrollo de la **Pre-Entrega 1 (PE1) del curso de JavaScript de Coderhouse**, correspondiente al Módulo 1: *Primeros pasos con JavaScript*.

El proyecto consiste en un pequeño programa interactivo que solicita información al usuario, procesa los datos ingresados mediante operaciones matemáticas y devuelve los resultados a través de mensajes en pantalla.

## Objetivo

Aplicar los conceptos fundamentales de JavaScript mediante la construcción de un primer flujo de interacción con el usuario, incorporando:

- Declaración y utilización de variables (`let` y `const`).
- Captura de información mediante `prompt()`.
- Conversión de tipos de datos.
- Operaciones aritméticas.
- Concatenación de cadenas de texto.
- Comunicación de resultados mediante `alert()`.

## Funcionalidades

El programa solicita al usuario los siguientes datos:

1. Apellido.
2. Nombre.
3. Año de nacimiento.
4. Peso (en kilogramos).
5. Altura (en metros).

A partir de la información ingresada, realiza dos operaciones:

- **Cálculo de edad:** determina la edad del usuario mediante la diferencia entre el año actual y el año de nacimiento.
- **Cálculo del índice de masa corporal (IMC):** obtiene el resultado dividiendo el peso por el cuadrado de la altura.

Finalmente, presenta los resultados mediante ventanas de alerta (`alert()`).

## Tecnologías utilizadas

- **HTML5:** estructura del documento web.

No se utilizan frameworks ni librerías externas.

## Ejecución

1. Clonar o descargar este repositorio.
2. Abrir el archivo `index.html` en un navegador web.
3. Seguir las instrucciones de las ventanas emergentes (`prompt()`).
4. Visualizar los resultados obtenidos mediante las alertas (`alert()`).

## Conceptos aplicados

Este ejercicio permite consolidar los primeros conocimientos de JavaScript, especialmente el manejo de variables, tipos de datos primitivos, conversión de valores y métodos de interacción propios del navegador.

Constituye el punto de partida para incorporar progresivamente nuevas herramientas y estructuras de programación en las siguientes etapas del curso.
